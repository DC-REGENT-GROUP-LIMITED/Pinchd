# Product source of truth

The existing product requirements and technical blueprint is the source document for Pinchd's product scope. Keep it intact in the project Library and link it here when the team decides where canonical project documents live.

Core product principles from the blueprint:
- Inclusive adult audience, with serious relationships as a focus while not excluding casual dating.
- Reciprocal recommendations and explainable compatibility signals.
- Essential profile, discovery, mutual match, messaging, report and block flows available without requiring a subscription.
- Privacy, safety and anti-abuse controls are launch requirements.
- Sustainable monetisation should focus on optional convenience, not selling safety or basic mutual connection.
- Launch density and support capacity matter more than launching everywhere immediately.

Before build freeze, validate launch geography, age assurance, verification approach, pricing, message limits, sensitive data handling, legal scope, and success metric definitions.
