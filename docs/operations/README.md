# Operations runbooks

Add and maintain runbooks for:
- Incident response and escalation.
- Safety/moderation surge and urgent reports.
- Account takeover and credential abuse.
- Data exposure and privacy incidents.
- Billing reconciliation and refunds.
- Database restore and disaster recovery.
- Queue lag, notification failure and message delivery degradation.
- Release rollback and schema migration failure.
- Vendor outage and vendor exit.
