# Pinchd brand assets

This directory is the source of truth for the current Pinchd brand artwork.

## Approved palette

| Name | Hex | Intended use |
| --- | --- | --- |
| Charcoal | `#111111` | Primary text, logos, dark surfaces |
| Terracotta | `#E07A5F` | Brand accent, highlights, primary actions |
| Warm Grey | `#E5E5E5` | Borders and secondary surfaces |
| Off White | `#FAF9F7` | Light backgrounds and cards |

## Asset map

- `logos/Pinchd-logo.png` — primary raster wordmark.
- `logos/pinchd-logo.svg` — scalable vector wordmark; prefer this where SVG is supported.
- `app-icons/App-Icon.png` — default app icon.
- `app-icons/App-Icon-dark.png` — dark variant.
- `app-icons/App-Icon-alternative.png` — alternative icon concept.
- `web/favicon.png` — browser favicon artwork.
- `source/App-Icon.ai` — editable Illustrator source file.
- `reference/Pinchd Dating App Brand Identity Board.png` — visual reference board.

## Brand direction

Pinchd should feel bold, modern, premium, and gender-neutral. Use the abstract P mark and restrained terracotta accent; avoid making hearts or overtly romantic decoration the central identity.

## Implementation notes

- Treat these as the approved initial assets, not final platform-export specifications.
- Before app-store submission, generate and validate platform-specific icon sizes and safe areas from the selected master icon.
- Keep the palette values consistent across mobile, web, and marketing materials.
- If the primary logo or app icon changes, update this guide and any app/web references in the same change.
